# Dashboard Analítico Universitario

## Descripción
Proyecto de visualización de datos universitarios usando Streamlit.

## Tecnologías
- Python
- Streamlit
- Pandas
- Matplotlib
- Seaborn

## Archivos
- app.py
- requirements.txt
- university_student_data.csv

## Ejecutar localmente

pip install -r requirements.txt

streamlit run app.py
